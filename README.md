# NutriPlan

NutriPlan is a responsive web application that brings recipe discovery, weekly meal planning, and grocery shopping together in one simple experience. Users can explore recipes, organize meals by day, and keep track of the ingredients they need for the week.

## Links

- [🌐 Live Demo](https://NutriPlan.netlify.app)
- [💻 GitHub Repository](https://github.com/m-egas/NutriPlan.git)

## Features

### Recipe discovery

- Browse a collection of recipes in a responsive card layout.
- Search for recipes by name.
- Filter recipes by Meal Type and Health Labels.
- Open recipe cards to view detailed recipe information, ingredients, and nutritional information.

### Weekly meal planner

- Plan meals for seven days, from Monday to Sunday.
- Organize meals into Breakfast, Lunch, and Dinner.
- Remove individual recipes or clear the entire weekly plan.
- Save the weekly meal plan.

### Grocery list

- Add ingredients from planned recipes to the grocery list.
- Add custom grocery items manually.
- Mark items as completed.
- Remove completed items.
- Clear the entire grocery list.
- Receive toast notifications for important actions.
- Store grocery list data using LocalStorage.

### Responsive Design

- Optimized for desktop, tablet, and mobile devices.
- Responsive layouts and spacing throughout the application.
- Clean, simple interface focused on usability.

## Installation

### Prerequisites

Make sure you have Node.js and npm installed on your computer.

### 1. Clone the repository:

Clone the repository and navigate to the project folder.

```bash
git clone https://github.com/m-egas/NutriPlan.git

cd NutriPlan
```

### 2. Install the dependencies:

```bash
npm install
```

### 3. Start the development server:

Open a terminal and run:

```bash
npm run dev
```

### 4. Open the app

Open the local URL provided by Vite in your browser.

You are now ready to explore NutriPlan :)

## Project Goal

The goal of NutriPlan is to create a simple and intuitive way for users to manage their meals and grocery shopping in one place.

The application brings recipe discovery, weekly meal planning, and grocery list management together in a single experience, helping users go from choosing recipes to planning their week and organizing the ingredients they need.

Discover → Plan → Shop → Cook
